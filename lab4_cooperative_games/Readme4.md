# Лабораторна робота №4: Кооперативні ігри

Програмна реалізація аналізу класичної кооперативної гри трьох осіб у формі характеристичної функції та знаходження справедливого поділу.

**Функціонал:**
- Перевірка умов суперадитивності та істотності кооперативної гри.
- Нормалізація характеристичної функції до 0-1 спрощеної форми.
- Розрахунок вектора Шеплі та перевірка його належності до С-ядра гри.

**Запуск:**
```bash
python main.py
```
