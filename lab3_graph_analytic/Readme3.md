# Лабораторна робота №3: Графоаналітичний метод

Програмна реалізація графоаналітичного методу розв'язання матричних ігор розмірностей (2×n) та (m×2) із побудовою обвідних.

**Функціонал:**
- Побудова ліній очікуваного виграшу та виділення нижньої (для 2×n) і верхньої (для m×2) обвідних.
- Автоматичний пошук точок оптимальності та ціни гри для матриць із сідловою точкою та без неї.
- Візуалізація розв'язків за допомогою `matplotlib` і виведення ймовірностей стратегій у консоль.

**Запуск:**
```bash
pip install numpy matplotlib
python main.py
```
