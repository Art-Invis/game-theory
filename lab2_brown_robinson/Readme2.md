# Лабораторна робота №2: Метод Брауна-Робінсон

Програмна реалізація ітеративного методу фіктивного розіграшу (Брауна-Робінсон) для знаходження наближеного розв'язку матричних ігор у змішаних стратегіях.

**Функціонал:**
- Автоматичний розрахунок емпіричних частот вибору стратегій.
- Формування верхньої та нижньої оцінок ціни гри на кожній ітерації.
- Візуалізація збіжності методу за допомогою `matplotlib`.

**Запуск:**
```bash
pip install numpy matplotlib
python main.py
