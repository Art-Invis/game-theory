# Лабораторна робота №5: Зведення матричних ігор до ЗЛП

Програмна реалізація точного розв'язання матричних ігор шляхом зведення до пари взаємно двоїстих задач лінійного програмування.

**Функціонал:**
- Автоматичне перетворення платіжної матриці зі зсувом для гарантування додатної ціни гри.
- Розв'язання прямої та двоїстої ЗЛП симплекс-методом за допомогою `scipy.optimize.linprog`.
- Зворотне перетворення результатів для отримання точних змішаних стратегій обох гравців та ціни гри.

**Запуск:**
```bash
pip install numpy scipy
python main.py
```
